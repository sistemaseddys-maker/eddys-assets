# Recursos visuales originales

Organización por categorías, igual que en el repositorio `eddys-assets`:

- `logos/`: originales de los logos.
- `login/`: imágenes y afiches para el login.
- `correo/`: encabezado y firma de los correos de recuperación.

Estos archivos no se sirven directamente desde la raíz web. Las copias utilizadas por PHP y React permanecen en `public/` y `poc-react/public/` para conservar las URL existentes. El envío de correo carga sus imágenes inline desde `assets/correo/`.

Las imágenes nuevas deben guardarse en su categoría. No almacenar aquí capturas de empleados ni documentos internos.
